## Criar um projeto

Inicie o plugin e o frontend seguindo [Instalação](instalacao.md). Na tela de projetos, cadastre uma pasta Java descartável e abra-a. Inicie o repositório Git pela interface. Se o projeto já tiver Git, confira qual branch foi selecionada.

## Editar o modelo

Abra um `.java` no explorador. A área central apresenta o modelo estrutural e o código. A biblioteca insere componentes, enquanto o painel de propriedades permite editar elementos selecionados. Crie um método simples, altere um valor e observe o código correspondente. Ao mover um método, confirme sua posição na classe e verifique o registro pendente antes de prosseguir.

## Registrar e consultar

No menu de commit, salve as mudanças sob um título descritivo. No histórico, selecione esse commit e abra uma mudança individual. Compare os estados anterior e posterior na visualização do código ou do modelo. O [manual](manual.md) descreve os outros painéis e a [implementação](implementacao.md) explica de onde vêm esses estados.
