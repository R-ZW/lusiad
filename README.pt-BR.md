# `Lusiad` – Programação baseada em modelos com rastreamento de mudanças

[🇺🇸 English](README.md) · **🇧🇷 Português (Brasil)**

O Lusiad permite editar código-fonte Java como um modelo de blocos aninhados e rastrear alterações individuais. O plugin do IntelliJ IDEA fornece acesso à Program Structure Interface (PSI), e a interface web apresenta o modelo e o histórico de alterações.

- [`lusiad-backend/`](lusiad-backend/) — Plugin do IntelliJ IDEA, API HTTP local e esquema MySQL.
- [`lusiad-frontend/`](lusiad-frontend/) — Aplicação web Next.js e integração com o Git.
- [`docs/`](docs/) — Documentação em inglês e português brasileiro.

O projeto é distribuído sob a [licença MIT](LICENSE).
